# hcmute-dsc/.github

Repo đặc biệt của tổ chức GitHub **HCMUTE Developer Student Club** ([hcmute-dsc](https://github.com/hcmute-dsc)).

| File | Dùng để |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Giới thiệu CLB, hiện ở trang https://github.com/hcmute-dsc |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Quy tắc ứng xử. GitHub tự áp dụng cho mọi repo của tổ chức chưa có file riêng |

Thông tin CLB (tên, mô tả, liên hệ, dự án) lấy theo website [hcmute-dsc.io.vn](https://hcmute-dsc.io.vn), cụ thể là `config/site.js` của repo [hcmute-dsc.github.io](https://github.com/hcmute-dsc/hcmute-dsc.github.io). Khi website đổi thông tin, cập nhật file ở đây cho khớp.
